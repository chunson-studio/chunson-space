# FlClash 安装提示

完整版链接本组 C# 源文件。正常桌面启动只检查是否存在已识别的 FlClash 安装；不以运行状态、订阅或主端口是否就绪阻止进入主界面。预览、离线验证和内部辅助入口不运行安装提示。简洁版已停止维护。

- 缺少 FlClash：显示下载通知。点击后用默认浏览器打开官方发布页，关闭通知并退出本工具；用户自行下载安装、配置订阅后重新启动工具。关闭通知也退出，不打开浏览器。
- 已安装：直接进入主界面；FlClash 未启动、无法读取其进程模块或网络入口暂时不可用时，也不会出现准备窗口。需要网络的具体操作仍使用原有网络检查。
- 保留已运行便携版的进程路径发现、常见安装目录与注册表安装位置检查；可执行文件仍须通过 FlClash 文件描述校验。
- 软件不下载或运行安装包。浏览器打开失败保留通知并显示错误；已有便携版未运行时，可先启动 FlClash 再重开本工具。
- 不修改代理规则、订阅、系统代理、地区、时区或账号；不接受其他代理客户端代替 FlClash。

离线检查：完整版 `--verify-storage-ui <新目录>` 调用 `FlClashSetupChecks`，覆盖已安装但停止或运行状态不可确认时直接放行、没有订阅或端口就绪依赖、发现前后取消、缺失通知点击/关闭、浏览器打开失败，以及不抢焦点的通知渲染。浏览器与安装发现使用替身，不联网、启动 FlClash 或安装软件。

官方来源：https://github.com/chen08209/FlClash/releases/latest

FlClash 是单独安装的第三方软件，遵循其自身许可证；未合并入本项目 MIT 源码。
