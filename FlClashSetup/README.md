# FlClash 启动准备

完整版链接本组 C# 源文件。正常桌面启动必须找到 FlClash、确认其运行状态，并通过主端口归属检查。预览、离线验证和内部辅助入口不运行安装引导。简洁版已停止维护。

- 缺少 FlClash：显示下载通知。点击后用默认浏览器打开官方发布页，关闭通知并退出本工具；用户自行下载安装、配置订阅后重新启动工具。关闭通知也退出，不打开浏览器。
- 已安装：复用当前版本，不自动覆盖。可选取已有便携版 FlClash.exe 并打开。
- 已运行但入口未就绪：用户自行添加订阅、选择节点并保留主 HTTP / mixed 入口，再点“检查并继续”。仅打开浏览器不能算安装成功。
- 软件不下载或运行安装包。浏览器打开失败保留通知并显示错误；已有便携版未运行时，可先启动 FlClash 再重开本工具。
- 不修改代理规则、订阅、系统代理、地区、时区或账号；不接受其他代理客户端代替 FlClash。

离线检查：完整版 `--verify-storage-ui <新目录>` 调用 `FlClashSetupChecks`，覆盖缺失、停止、端口不可用、取消、通知点击/关闭、浏览器打开失败，以及不抢焦点的界面渲染和继续/退出边界。浏览器与检测使用替身，不联网或安装软件。

官方来源：https://github.com/chen08209/FlClash/releases/latest

FlClash 是单独安装的第三方软件，遵循其自身许可证；未合并入本项目 MIT 源码。
