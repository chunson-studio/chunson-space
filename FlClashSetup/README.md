# FlClash 启动准备

完整版与简洁版链接同一组 C# 源文件。正常桌面启动必须找到 FlClash、确认其运行状态，并通过各版本已有的主端口归属检查。预览、离线验证和内部辅助入口不运行安装引导。

- 缺少 FlClash：用户点击后，从 chen08209/FlClash 官方 v0.9.0 发布下载 Windows amd64 安装程序，核对 42,807,184 字节与 SHA-256，再打开官方安装向导。安装位置、许可和提权由安装向导处理。
- 已安装：复用当前版本，不自动覆盖。可选取已有便携版 FlClash.exe 并打开。
- 用户自行添加订阅、选择节点并保留主 HTTP / mixed 入口。返回“检查并继续”后重新检查；仅打开安装向导不能算安装成功。
- 下载失败、大小或校验不符、取消均不得执行文件。关闭准备窗口退出本次工具启动。下载仅存在本机 LOCALAPPDATA/ChunsonSetup，不发布到源码。
- 不修改代理规则、订阅、系统代理、地区、时区或账号；不接受其他代理客户端代替 FlClash。

离线检查：简洁版 `--verify <新目录>`、完整版 `--verify-storage-ui <新目录>` 共用 `FlClashSetupChecks`，覆盖缺失、停止、端口不可用、取消、损坏安装包、现有安装保留，以及不抢焦点的界面渲染和继续/退出边界。夹具不联网、不运行安装器。
